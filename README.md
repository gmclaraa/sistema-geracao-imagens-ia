# 🖼️ Gerador de Imagens com IA

Projeto desenvolvido para praticar o desenvolvimento Front-end com React, integrando uma aplicação moderna à API da Hugging Face para geração de imagens por inteligência artificial. A aplicação permite inserir uma descrição e gerar uma imagem dinamicamente a partir do prompt informado.

## 💻 Sobre o projeto

A proposta foi criar um gerador de imagens utilizando inteligência artificial. Através de uma interface simples e estilizada com CSS personalizado, o utilizador pode descrever a imagem que deseja gerar e visualizar o resultado diretamente na aplicação.

A geração das imagens é realizada utilizando o modelo `FLUX.1-schnell`, disponibilizado através da Hugging Face.

## 🔍 Funcionalidades

- Geração de imagens a partir de descrições
- Campo para inserção de prompts
- Exibição de imagem padrão antes da geração
- Geração dinâmica de imagens com IA
- Integração com o modelo `FLUX.1-schnell`
- Exibição da imagem gerada diretamente na interface
- Interface estilizada e responsiva
